Why Swasth Succeeds

Engineered to Prevent Long-Term Dropouts

The Daily Hook

Culturally rooted Garbh Sanskar micro-habits (IQ, EQ, PQ, SQ), calming raga music, and partner bonding that mothers look forward to every morning.

Birth Clubs & Circles

Hyperlocal peer circles connecting mothers in the same PHC radius for mutual comfort, recipes, and logistical guidance with NeMo Guardrails moderation.

Care Continuity Bridge

Automated vaccination cohort tracking (6, 10, 14 weeks) and doctor-approved weaning diet schedules seamlessly delivered alongside daily habits.

24/7 Offline Sync

Engineered for low-connectivity rural health centers. Functions 100% offline and synchronizes encrypted state to PostgreSQL when online.

Enterprise Open-Source Architecture

Unified Microservices Stack

Client Layer
Flutter & React
  • • Flutter Mobile: 60 FPS iOS/Android
  • • React/TypeScript: Web backup
  • • Encrypted offline SQLite/local cache
Unified Backend
Python (FastAPI)
  • • Single unified REST & WebSockets
  • • Asyncpg with connection pooling
  • • Sub-5ms API response latency
Agent Pipeline
LangGraph + vLLM
  • • Open models: NVIDIA Nemotron / Llama 3
  • • PagedAttention vLLM serving
  • • State-aware milestone workflow
Indic Voice & NLP
Whisper & IndicTrans2
  • • Open-source Whisper voice notes
  • • AI4Bharat IndicTrans2 (10+ languages)
  • • Low-literacy audio prompts
Data & Governance
PostgreSQL Ledger
  • • Row-level security for ABHA IDs
  • • Append-only compliance audit trail
  • • Human-in-the-loop signoff logs
100% Assistive · Strict Non-Clinical Scope
Zero diagnostic advice, zero medication prescribing, zero medical risk scoring. Powered by NVIDIA NeMo Guardrails to intercept clinical red flags and route immediately to primary health centers.
